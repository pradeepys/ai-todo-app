# Task Galaxy OS Specification Prompt

This file documents the core prompt and requirements list used to construct **Task Galaxy OS**.

---

## Specification

### Technologies
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- No frameworks or external UI/animation libraries (React, Vue, Tailwind, Bootstrap, jQuery, etc.)

---

## Product Vision: Task Galaxy OS
This is a futuristic productivity operating system where tasks act as living entities inside a digital universe.

### Core Visuals
- Active tasks orbit a central core.
- Completed tasks turn into stars.
- High-priority tasks emit glowing energy fields.
- Imploding particle animations.

---

## System Requirements

### 1. Animated Background Systems
- Layer 1: Gradient mesh
- Layer 2: Cosmic particle stream
- Layer 3: Aurora drift
- Layer 4: Starfield
- Layer 5: Cursor lighting depths

### 2. Custom Interactive Cursor
- Hover expansion, trails, magnetic attraction, and click ripples.

### 3. Glassmorphism Design Theme
- Frosted panels, neon edges, backdrop blurs, and floating cards.

### 4. Advanced Task Manager Lifecycle
- **Add**: Instant slide-in animations.
- **Edit**: Double-click inline change bindings.
- **Complete**: Checkbox glow pulse, stardust confetti, and status transition.
- **Delete**: Dissolve particle burst with a 5-second Toast undo callback.
- **Priority Tiers**: Critical, High, Medium, Low with matching glow colors.
- **Categories**: Work, Personal, Study, Fitness, Finance, and custom category emblems.
- **Due Dates**: Deadlines with overdue, due soon, and normal labels.
- **Recurrence**: Daily, weekly, monthly, and yearly orbital intervals.
- **Subtasks**: Unlimited nested subtasks with progress tracker bars.
- **Attachments**: Local file loading stored as base64 string configurations.

### 5. Multi-Dimension Views
- **List View**: Active/completed anomalies.
- **Grid View**: Modern compact dashboard cards.
- **Kanban View**: 3 dragging swimlanes (Todo, Progress, Done).
- **Timeline View**: Chronological vertical milestones.
- **Calendar View**: Monthly calendar with grid scheduling double-click triggers.

### 6. Focus Mode & Pomodoro
- Fullscreen overlay showing one task, progress circle, breathing guides, and procedural synthesizers (Space Hum, Rain, Lofi Synth).

### 7. Gamification System
- Earn Gold & XP. Unlock level ranks.
- Unlocking achievements (First Orbit, Stellar Success, Space Explorer, Aether Tycoon).

### 8. Theme Options
- Cosmic Dark, Cyberpunk Grid, Aurora Forest, Ocean, Sunset, Greenwood, Minimal White, AMOLED, Royal Purple, Matrix Green.
- Custom color picker builder.
